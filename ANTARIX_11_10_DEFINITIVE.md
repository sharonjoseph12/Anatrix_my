- AI Coach recommendations (pushed via WhatsApp/notification)

Colleges buy dashboards to see placement readiness. Companies search verified candidates. Everyone wins.

# 3. DATA COLLECTION (TWO LAYERS)

## Layer 1: Passive Tracking (Zero Effort — All Students)

Student connects GitHub and Google Calendar once during onboarding. System handles everything automatically.

### GitHub (Auto-Sync Every 2 Hours)
```
What we capture:
- Commits (hash, message, timestamp, files changed, additions/deletions)
- Repositories (name, description, stars, forks, is_private)
- Languages (per-repo language breakdown: Python 67%, JavaScript 23%)
- Commit patterns (time of day, day of week, streak length)
- Project completion signals (README presence, CI/CD, releases)
- Collaboration signals (PRs merged, issues closed, code reviews)

What we derive:
- Primary languages and expertise level
- Active projects and completion rates
- Coding velocity (commits/week trend)
- Peak coding hours (from commit timestamps)
- Specialization detection (ML repos, web repos, data repos)
- Consistency score (streak length, regularity)
```

### Google Calendar (Auto-Sync Every 6 Hours)
```
What we capture:
- Class schedule (recurring events)
- Deadlines (events with "deadline", "due", "submit" keywords)
- Free time windows (gaps between events)
- Study groups (events with multiple attendees)

What we derive:
- Available hours per day for coding/learning
- Schedule density (busy vs light days)
- Optimal suggestion timing ("You have 2 free hours before your 4 PM class")
- Deadline awareness for AI Coach nudges
```

### Day 1 Value (No Extension Needed)
```
Student connects at 10 AM.
By 10:30 AM, system has synced:
- 245 commits across 12 repos (last 90 days)
- Language breakdown: Python 67%, JavaScript 23%, SQL 10%
- 34 commits in last 7 days (active)
- Peak commit hours: 7-10 PM
- Calendar: 4 classes/day, free after 5 PM most days

By 11 AM, first insight generated:
"You code most between 7-10 PM. You have 2 free hours today after 5 PM.
Your Sign Language Recognition project had 12 commits this week — you're on a streak!"

No extension. No manual tracking. Pure value.
```

## Layer 2: Power Mode — Chrome Extension (Optional, Deeper Tracking)

Students who want richer insights install the Chrome Extension. Shows "⚡ Power Mode" badge on profile.

### What Extension Adds
```
- Session tracking: Start/stop work sessions with category tags
  Categories: DSA, Coding, Project, Learning, Research
- Real-time focus monitoring:
  - Tracks active window (VSCode, browser, etc.)
  - Monitors open tabs (productive vs distraction)
  - Calculates focus quality: HIGH (1-2 focused tabs), MEDIUM (3-5), LOW (5+ or distractions)
- Session completion: Duration, productivity self-rating (1-5), notes
- Offline-first: Stores locally, syncs hourly to backend
```

### Power Mode Advantages
```
Without Extension (Passive Only):
- Skill proof score based on GitHub + Calendar
- Peak hours from commit timestamps (good, not precise)
- Language-based skill detection
- Basic placement prediction

With Extension (Power Mode):
- All of the above PLUS:
- Session-level granularity (what category, what project, how long)
- Real-time focus quality scoring
- Workflow pattern detection (DSA→Coding→Docs = 84% success)
- More accurate peak window (from actual sessions, not just commits)
- Richer AI Coach recommendations
- 2x more data points → higher confidence insights
- "⚡ Power Mode" badge on profile → companies see deeper data
```

# 8. SKILL PROOF SCORE (How It Works)

## Calculation (0-100)

### For Passive-Only Students (No Extension)
```
GitHub Activity Score (50% weight):
- Commit frequency and consistency (15%)
- Language diversity and depth (15%)
- Project completion signals (README, releases, CI) (10%)
- Collaboration (PRs, code reviews, issues) (10%)

Calendar Context Score (10% weight):
- Schedule management (10%)

Consistency Score (20% weight):
- Streak length and regularity (10%)
- Activity trend (improving/declining) (10%)

Peer Context Score (20% weight):
- Percentile rank within cohort (10%)
- Specialization depth vs breadth (10%)
```

### For Power Mode Students (Extension Installed)
```
All of the above PLUS:

Session Quality Bonus (replaces Calendar Context, 25% weight):
- Hours logged per skill (10%)
- Focus quality during sessions (10%)
- Session completion and notes (5%)

Adjusted weights:
- GitHub Activity: 35%
- Session Quality: 25%
- Consistency: 20%
- Peer Context: 20%
```

### Proficiency Levels
```
0-29:   Beginner
30-59:  Intermediate
60-84:  Advanced
85-100: Expert

Placement Ready: Score ≥ 80 AND active in last 30 days
```
